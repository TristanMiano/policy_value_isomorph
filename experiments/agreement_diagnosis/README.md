# Data for the move-agreement diagnosis

The frozen **original** chooses its highest-scoring legal move. **Direct selection** takes the largest fitted move frequency. **V** uses only the board after a move. **Q** also sees the current board and candidate move. **Von Neumann–Morgenstern (VNM) selection** compares expected utilities, numerical scores of complete plays. Here the ordinary copies choose deterministically, so a single exact continuation per candidate gives its expectation. Tables name the utility and continuing player. [Findings, definitions, and proofs](../../AGREEMENT_DIAGNOSIS.md) · [Design and subsequent exploratory interventions](DESIGN.md)

## Which comparisons to read

- [Training-control tables](training_tables.md) pool all visited boards for fitting. This is the perfect initial-agreement comparison. The Q all-paths control also fits the entire continuation of every initial alternative. Use [all results](training_results.jsonl.gz) and [paired source differences](training_contrasts.jsonl.gz) for unrounded estimates, each source's difference, both Student and resampling 95% intervals and adjusted p-values.
- [Earlier withheld-board diagnosis](tables.md) uses the original Phase V board and game weights. It includes direct, terminal and centered VNM selection, controlled score/continuation replacements, additional training coverage, normalized action fits and the game-rule-assisted models. [All source-level results](results.jsonl.gz) · [Paired source differences](contrasts.jsonl.gz) · [Examples with predicted and observed counts](count_examples.json).
- [Phase V baseline records](../phase_v/README.md) and [tic-tac-toe fitting records](../phase_iv/README.md) contain the original weights, observations, opponent definitions and games corresponding to the withheld-board analysis. The independent unit is an original player with its two collections and two initializations. Retained repetitions are 32/24/24 originals for tic-tac-toe, Connect Four and 4×4 Reversi. All present experiments concern fixed-choice originals. The Reversi originals share their optimal favorite at every board. An exact control can remove a source of earlier variation, particularly the effect of the initialization.

## Individual records

A block is a source directory such as `connect4/block_00`. File suffixes `k_f` denote collection or board partition k and recovery initialization f, each 0 or 1. Compressed JSON lines files contain one JSON object per line. Named numeric arrays in NPZ files can be read with NumPy. Read Reversi cells in row order from zero, including forced pass 16. In Connect Four bit 7×column + height counts from the bottom of each column. The two occupied-cell integers are followed by the seat to move, zero for the first player. Tic-tac-toe board strings run in row order.

| Files per block | Data and units |
|---|---|
| `control_visits_k.npz` | All observed training roots, raw move counts, and indices of the V control's disjoint-successor training parents. For the larger games `continuation_counts` adds the two occupancy integers, seat, freely chosen move and number of observed visits on paths following each forced alternative. The forced first alternative contributes no move-count observation. Root order is shared by the control scores. |
| `control_cases_k_f.npz`, `control_sums_k_f.npz` | Immediate and final candidate scores, original move, visits and whether each forced path has fitted inputs throughout. Also includes archived choices for all-move and discounted VNM. Separate game arrays give realized points where games are sampled. With a finite set of observed inputs, the fit is the exact minimum of squared error against count/parent visits, with each legal candidate equally weighted. For V pooling, shared successor inputs receive their mean target. For uncovered inputs in the larger games the background is twelve random pattern weights per candidate, each drawn with mean 0.5/12 and standard deviation 0.012, summed and bounded to [0,1]. Tic-tac-toe uses independent uniform successor scores for the background. The path-covered Q scores never use this background at the evaluated roots or when continuing from them. |
| `training_control.jsonl.gz`, `training_sums.jsonl.gz` | Absolute agreement, whole-game win/draw/loss, game points, exact-match loss attribution and fitting counts by rule and initialization. `match` weights positions equally and `visit_match` weights their original visits. `all_paths_covered` is the fraction of roots where **every** alternative and all downstream direct decisions use fitted inputs. For Q every legal score at a fitted parent is determined by its normalized counts. For V the inputs for every compared downstream move are checked. In tic-tac-toe full-game probabilities are exact given the policies. |
| `boards_k_f.npz`, `diagnosis.jsonl.gz` | Withheld cases, legal masks, population weights, actual counts, source choices and candidate scores in double precision, and per-fit measured effects. Endpoint arrays give path length, final mover sign relative to the player choosing, exact normalized frequency of the final move and its fitted frequency. The first path uses fitted continuations, the second uses the original. `switch` measures the partition of changed choices. `strict` counts a strictly beaten source favorite. The field `lost_tie` counts a tied favorite when the convention chooses another eligible move. |
| `extra_k.npz`, `expanded_weights_k_f.npz` | Additional 4,096 training starts, aggregate original and added counts, original input partitions plus newly observed training parents, and expanded V/Q weights. The validation and evaluation populations are inherited. The normalized target is count divided by parent visits. An existing training board can acquire more visits. |
| `normalized_original_k_f.npz`, `normalized_expanded_k_f.npz`, `choice_fit.jsonl.gz` | Fitted board-pattern weights for the probability model, scores on every evaluated case, shared game outcomes, teacher choices and optimization records. Exponentiate each candidate score and normalize over legal moves to obtain a probability. Fit using each board's observed count fractions, equal weight per board, negative log probability and a squared-weight penalty. The saved `training` value is mean unpenalized negative log probability. The field `objective` includes the penalty per fitting board. |
| `ordered.jsonl.gz`, `example_Q.json`, `example_V.json` | On both small solved games, rules-based tie comparisons on the fitting set, fitted priority orders, all-board counts and panel outcomes. The example files in block 00 show actual alternative paths, root scores and final scores of the earlier imperfect V/Q fits. |
| `rule_inputs_weights` and `action_only_weights` in the board archives | The small fitted model uses one numerical preference per move. Optional features are the game outcome guaranteed against perfect replies (tic-tac-toe/Reversi) or immediate win and block indicators (Connect Four). Apply the same legal-move probability normalization. The penalty is 0.005 times the squared weights. The model fits training choices alone. In Reversi one unused auxiliary feature has coefficient zero at the optimum. The ordered extension ranks observed choices among best-outcome moves and tries both low- and high-index conventions to complete unobserved preferences. |

For the in-sample comparisons, all starting parents count as training parents. Alternative paths in the Q all-paths control can contain further fitted parents outside this root population. Games against external opponents can visit new boards. For the original split analysis, the training agreement diagnostic for V only uses fitting parents with every legal candidate eligible for fitting. The attainable shared-successor frequency projection uses all incoming legal candidates of the full game graph for tic-tac-toe and Reversi. Connect Four uses only that collection's observed and evaluated parents, with full-information labels. It is a diagnostic of those finite sets. When raw or tabular scores are exact and many candidates tie, tiny score differences and the index convention can matter. All tie diagnoses use the actual unrounded scores and the stated convention.

## Reproduction

Run from the repository root on Linux or Windows Subsystem for Linux with the [Phase V dependencies](../phase_v/README.md#running-from-the-repository-root), the archived Phase IV/V inputs, and a C++17 compiler. These commands reproduce the diagnosis and its separate training control. The largest data collection only needs complete continuations of the original at the specified roots. No full Connect Four game tree is enumerated.

```sh
python -m pip install -e ".[dev,phase-v]"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
python scripts/diagnose_agreement.py
python scripts/diagnose_choice_fit.py
python scripts/diagnose_tied_moves.py
python scripts/report_agreement_diagnosis.py
python scripts/diagnose_training_control.py
python scripts/diagnose_training_sums.py
python scripts/report_training_control.py
python -m pytest -q
python scripts/demo_tictactoe.py
```

The native helper `centered_vnm(model)` selects the centered utility with fitted copies. Passing `original_continues=True` changes the continuing player. For tic-tac-toe `trajectory_scores(paths, x_scores, x_local_best=...)` returns the signed sum of local shortfalls under `vnm_centered`. These options leave the earlier terminal, sum and discounted benchmarks available for paired comparisons.
