# Reproducing the three-game measurements

The frozen **original** is a trained network that returns a score for every legal move. A fixed player takes its highest score, resolving exact ties by the lowest move number. A randomized player takes that move with probability ¾ and otherwise draws uniformly. The **V network** learns an observed move frequency from the resulting board alone. **Q** also receives the original board and candidate move. **Direct selection** chooses the largest fitted frequency. **Von Neumann–Morgenstern (VNM) selection** tries a move, finishes the game under a specified continuation and compares the expected numerical score of the complete play for each candidate. Both sides continue by the same fitted direct policy or by the frozen original as named. ## Sampling, labels and uncertainty

A **block** is one independently trained original, its opponents, two randomized partitions with separate observation collections, and two independently initialized recovery fits per partition. There are 32 blocks for tic-tac-toe and 24 each for Connect Four and Reversi. The fixed and randomized behaviors in one block share the original. Each new-game collection has 96 games from the natural start plus either one or three games from each of 384 random prefixes. A prefix is a board sampled along a legal game between uniform players. A second pool supplies Connect Four holdouts. Reversi holdouts sample from an independently enumerated reachable game graph. The fixed Reversi originals have identical preferred moves; alternative rankings and all sampling and recovery streams can vary. The per-block seed function combines game, block, stage, split and fit. Each fitted-model/comparison pair reuses the same cases and random number per actual game turn.

Each **holdout** contains positions reserved for evaluation. Splits keep symmetry-related positions together. Parent input partitions are approximately 65% fitting, 15% validation and 20% holdout, with the opening reserved. The V fit also removes resulting-board inputs shared with reserved groups. Across positions in the primary evaluation, weight each sampled Connect Four board equally. In Reversi each sampled position represents the number of withheld boards in its group divided by the number sampled in that group. For visits under the original's own play, use the separate visit weights. For every sampled game estimate average the four opponent groups equally and both seats equally. Full-game probabilities in tic-tac-toe are exact conditional on its players, random-move rules and normal start. Its earlier board collections started at each decision board and used a richer neural fitting architecture. [Tic-tac-toe configuration](../../PHASE_IV_PROTOCOL.md)

A **paired difference** compares methods on the same fit, source and cases. Independent units for uncertainty are whole source blocks. Average the four fits first. The sample standard deviation describes variation between independent block means. Individual 95% Student intervals and two-sided p-values use the variability across original blocks. A p-value gives the probability, under a zero-mean reference model, of a result at least this extreme. Holm's adjustment accounts for the 24 primary comparisons. Additional differences use a separately labeled exploratory family, with separate adjustments for the descriptive rankings, fixed-control comparisons, six head-to-head contrasts and 16 supplementary question comparisons. A missing p-value indicates an inestimable standard error, including zero spread. Within-game resampling takes 5,000 whole-block draws and preserves the two equal-sized teacher groups in Connect Four. Three-game resampling draws independently within each game before taking the unweighted mean of the three means. Its analytical interval uses each game's own variance and degrees of freedom. Its reported spread is the standard deviation under an independent draw of one original per game followed by averaging. The combined target is these three named games under their own distributions.

## Reading individual records

A file ending in `.jsonl.gz` is compressed text with one JSON record per line. Open it with Python's `gzip.open(path, "rt")` and parse each line with `json.loads`. An `.npz` file contains named numerical arrays read by `numpy.load`. In the new games the suffix `k_m_f` means partition 0/1, fixed/randomized behavior 0/1 and initialization 0/1. Files shared between two fits omit the final index. A state has two occupied-cell integers followed by the seat to move, 0 first and 1 second. In Connect Four bit 7×column + height marks a disc, with height zero at the bottom; moves are columns 0–6. In Reversi bits/cells 0–15 run in row order starting at the top left. Move 16 is a forced pass and switches the seat.

## Model and result names

- Model numbers 1 and 2 are V and Q; 7 and 8 use a second arrangement of the same number of pattern groups. Model 0 is the original. Model 3 is the imitator, which maximizes the probability of observed moves using the same new-game Q features. Model 4 fits original legal score differences with privileged numerical output access. Model 5 pools action counts over all training boards. Model 11 learns the restricted-choice rankings. Model 6 predicts final game points. Models 12–14 predict observed probabilities of win, draw and loss; model 15 bounds the three scores, normalizes their sum and returns the win probability minus the loss probability. An all-zero sum maps to zero. These outcome models train only where a move was observed.
- `VNM_terminal`, `VNM_sum` and `VNM_decay` compare signed frequencies of the final move, sum over all moves, and a sum weighting each successive turn by 0.9. A first-player move has positive sign, a second-player move negative. Reverse the final score for a second-player decision. Continuations with `copies` use fitted direct copies; `source` consults the frozen original. Each deterministic continuation uses one path per candidate. Randomized original continuations use four paths per candidate in the new games and sixteen in tic-tac-toe.
- `supplied_VNM` scores terminal outcomes by +1, 0 and −1 for first-player win, draw and loss. `compact_VNM` estimates one common first-player draw value in [−1,1] from up to 128 training boards while retaining the win and loss values. These new-game names use fitted Q continuations unless suffixed `source`. In the historical tic-tac-toe controls the unqualified compact/supplied names use original continuations and `copies` identifies fitted continuations. `random_utility_VNM` mixes equally between draw values −1 and +1, using one sampled utility per decision. `masked_VNM` uses the original's support (the legal moves it takes with positive probability) as additional information.
- `max` chooses the first highest score. `T0` splits tied highest scores equally. For positive temperature T a move gets weight exp(score/T), normalized over legal moves. `Tselected` chooses among 0, 0.05, 0.25 and 1 by validation probability error separately for each rule. `Ttransfer` uses the setting selected on the other 23 originals' validation observations for a new game. Probability error (`tv`) equals half the sum of absolute differences between the two distributions; lower is closer. Independent-draw agreement is the sum of source probability times reconstructed probability over legal moves. Diversity is the expected number of different moves in eight independent draws at the same board, or the observed distinct boards in eight complete games where specified.
- Source-level scopes `performance`, `positions_0/1/2`, `paired_decisions`, `seats_i_j` and `duels_i` select overall measurement, decision groups, unweighted case categories, seat/opponent group and head-to-head seat. Scopes `remove_favorite`, `remove_other`, `removed_move`, `swap_first_two` (historically `edited_priority`), `coverage`, `curve`, `training`, `stability`, `queries`, `eight_games` and `changed_continuation` select the other studies. Each statistical row identifies its actual comparator in `reference` when one is defined. The schedule of interventions and data access is in the [frozen design](../../PHASE_V_PROTOCOL.md).

## Running from the repository root

Use Python 3.10 or newer, PyTorch, NumPy and SciPy on Linux or Windows Subsystem for Linux (WSL). The native simulator uses a C++17 compiler with Python development headers and the bindings included with PyTorch. It builds in the system temporary directory. Matplotlib generates the saved figure. Set `PVI_PHASE_V_OUTPUT` to an empty directory for a separate reproduction. Keep the archived Phase IV input available for the tic-tac-toe reduction. Limit CPU library threads per worker to avoid multiplying memory and thread use.

```sh
python -m pip install -e ".[dev,phase-v]"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
python scripts/plan_phase_v.py
python scripts/run_phase_v.py source
python scripts/phase_v_sources.py
python scripts/run_phase_v.py fit
python scripts/run_phase_v.py evaluate
python scripts/run_phase_v.py diagnostics
python scripts/phase_v_bounds.py
python scripts/phase_v_diversity.py
python scripts/phase_v_pairs.py
python scripts/phase_v_tictactoe.py
python scripts/report_phase_v.py
python scripts/phase_v_tables.py
python scripts/plot_phase_v.py
python scripts/phase_v_atlas.py
python -m pytest -q
python scripts/demo_tictactoe.py
```

For a single new-game source and its two partitions use `--games reversi4 --blocks 0 --workers 1` on the four staged commands. Completed blocks are reused. Use `--force` to regenerate the selected stage, then rerun its dependent stages. The script publishes outputs after each complete block stage. The original pre-fit baseline can be compared directly to every evaluation's frozen-source game scores and turns. The tests independently recompute the planned differences by comparing raw probabilities and outcomes, check the cross-game weights and passes, and independently sum complete plays under both continuation rules.
