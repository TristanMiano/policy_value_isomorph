# Learning which move the frozen tic-tac-toe player will choose

The **source** is the frozen neural player whose move we want to reproduce. **Minimax** gives the best outcome a player can guarantee against an opponent making the best possible reply. Our source chose the lowest-numbered minimax move on all 4,520 reachable boards with a legal move. Its average and largest guaranteed payoff given up were both zero, with a win worth +1, a draw 0 and a loss −1. **Agreement** counts the boards where a reconstruction chooses that exact cell. A different move can preserve the same payoff.

A neural network fitted to the complete visit table reproduced the source on **4,520/4,520 boards**. On 780 boards omitted from fitting, supplying board geometry and modeling how the source resolves ties raised average direct agreement from **83.72% to 96.45%** for a network scoring the board and move, and from **71.11% to 93.76%** for a network scoring the resulting board. A separate model recovered all 780 withheld moves when supplied with the stronger assumption that both players plan to the end against best replies.

## What the networks learned from

The source takes nine cells and the side to move as inputs, uses two hidden layers of 128 units, and chooses the highest-scoring legal cell among nine outputs. Each hidden unit keeps positive inputs and returns zero otherwise. It was trained on the lowest-numbered minimax move on all decision boards using the negative log probability of the target, batches of 256 and Adam (an optimizer that scales updates using past gradients), with an initial step size of 0.003. It reproduced all teacher choices after 80 passes, with initialization 7101. We loaded those weights and checked every board before evaluating reconstructions. [Source training](NEURAL_TICTACTOE_CONTROL.md)

A **visit frequency** is the number of times the source took a move divided by all observations at that board. The source always selects the same move, so one visit identifies all its move frequencies there. Our main comparison used the archived complete games started once at every board. There were 2,980 boards for fitting, 760 for choosing the training duration (validation), and 780 reserved for evaluation (test). The 2,980 training starts took 7,082 source turns and retained 5,702 observations from training boards. Rotations and reflections of a parent board stay in the same group. The source knew every board when learning its own policy. The recovery fits receive only their permitted training labels and validation labels for selecting a checkpoint, the weights saved at a particular training pass. [Counts, denominators and sampling rules](TICTACTOE_SAMPLING.md)

We also repeated the comparison at 8,192 source observations. One quarter of those games start empty. The rest start from the least visited of 16 positions generated by random legal moves at varied depths. Half the games use two source copies and half use a uniformly random opponent. Only source turns count. The three collections are paired with the three network initializations. The original 780 test boards have been examined in earlier experiments. A further check changes the board partition and initializations and refits the networks from scratch. All of these comparisons use the same finite game and source.

## Which training changes account for the gain?

A **board value network (V)** scores the board resulting from a candidate move. A **board-and-move value network (Q)** can also use the current position to distinguish different moves arriving at the same board. **Direct selection** chooses the highest immediate move score. Each comparison below uses the same withheld boards with equal weight and the same three initializations. A **standard error** is the sample standard deviation divided by the square root of the number of fits. For differences we subtract the two results within each paired fit first. The boards themselves form a complete finite test set.

- **Independent squared error** fits each legal move's probability separately by minimizing its squared difference from its observed frequency. **Independent binary log loss** changes that training loss to the negative log probability of the observed selection or nonselection. The scalar output in both cases is converted to a probability by the logistic function.
- **Joint choice** fits a distribution over all the legal moves at a board. It exponentiates their scores, divides by their sum (the **softmax** rule), and minimizes the negative log probability assigned to the observed move. **Raw** uses the original board and candidate-cell inputs. The **equal-width raw control** spreads the same inputs over as many coordinates as the geometry model with a fixed, distance-preserving linear transformation. It matches the number of network weights while supplying the same board information.
- **Geometry** counts unblocked winning lines containing one, two or three marks and distinct cells that complete a line, for both sides. It includes the board as seen by the mover, using the same orientation for rotated or reflected copies. For all legal replies it adds the minimum, mean and maximum of each line count, then repeats this operation for the next turn. These features use the game rules and up to two more moves from a candidate board. They can be computed without the source, game payoff labels or a perfect-play solver.
- **First acceptable** learns a probability that each legal cell is acceptable. The probability of choosing a cell is the probability it is acceptable times the probability every earlier legal cell was skipped, conditional on some cell being acceptable. We fitted it both with the cell index supplied to the network and with only rotation- and reflection-invariant geometry. In the latter case, cell number enters only through the choice rule.
- **Three learned levels** represents uncertainty over three ordered scores per candidate. Each candidate draws a level independently from its predicted probabilities. The highest level wins, with ties going to the earliest legal cell. We sum exactly over these possibilities and fit the resulting move probabilities to observed frequencies. This model is given the source's tie convention and a three-level hypothesis. Its only supervision is observed choices. The levels receive no win, draw or loss labels. Direct selection takes the most probable move, making the deployed choice deterministic.

At evaluation it compared all legal candidates. Q used all 2,980 training and 760 validation boards. These differences in information matter when comparing V and Q.

We take the first one eighth, quarter, half, three quarters or all of each ordering. The subsets are nested within a repetition and chosen without consulting move labels. Every eligible board in a retained group supplies its original normalized visit counts.

Every Q pass presented 2,980 board examples, and every V pass presented 978 eligible comparisons, regardless of subset size. With fewer boards we reshuffled and cycled through the available examples. This holds optimizer updates fixed and varies how many genuinely distinct positions the learner sees. The labels on the 780 test boards enter only the measurements. We also made a separate fixed-duration fit using the 760 former validation boards for training. It uses 3,740 non-test positions, keeps the same number of updates, and has no independent validation set for choosing duration.

## How closely were the observed counts fitted?

For board `s` and legal move `a`, the raw target count is `C(s,a)`. Its denominator is the number of observed source moves on that same board, `N(s) = Σ_b C(s,b)`. The training label is `y(s,a) = C(s,a)/N(s)`. A zero count at a visited board is a zero-probability label. An unvisited board has no label and is excluded. Repeated visits affect the estimate of the label, while each eligible move (independent objectives) or board (joint objectives) receives equal weight in the loss. For the joint V fit we retain boards where the chosen move survives exclusion of shared inputs, so the retained target probabilities still sum to one. Evaluation uses all legal moves.

**Squared loss** averages `(p−y)²` over eligible legal candidates, in squared probability units. **Binary log loss** averages `−y log p − (1−y) log(1−p)` over those candidates. **Joint log loss** averages `−Σ_a y(s,a) log p(s,a)` over boards. Here `p` is the network's estimated move probability. We use natural logarithms, so the logarithmic losses are in **nats** per candidate or per board, respectively. Lower values mean a closer fit under that objective. A predicted count is `N × p` at a specified number `N` of source visits. The count can be fractional because it is an expectation.

## How much does VNM selection help?

**Von Neumann–Morgenstern (VNM) selection** chooses the move with the largest expected learned utility of the complete play. For the visit-trained networks we take each candidate, then finish a legal game of tic-tac-toe. The utility is the sum of the fitted move frequencies along that path, positive for X moves and negative for O moves, multiplying each successive term by 0.9. X maximizes and O minimizes the expected sum. All ties use the lowest cell number. The same weights score the immediate move and every move in its continuation.

**VNM with source** uses the frozen player for both sides after the candidate, so it has additional source access during selection. **VNM with copies** uses two copies of the reconstruction's direct rule and needs no original-player queries. These players are deterministic, so one complete trajectory per candidate exhausts the continuation possibilities for each rule. During actual games the evaluated player uses its designated decoder on every turn, playing against the external opponent.

There is a direct explanation for the exact-copy case. If learned frequencies equal the deterministic source's true frequencies everywhere, the source move has immediate score one and every other move has zero. Both sides then follow the source, so the subsequent terms in the mover's utility are −0.9, +0.9², −0.9³ and so on until the game ends. The source move's total is strictly positive for any game length. A different first move's total is at most zero. The discounted VNM rule therefore reproduces this exact policy regardless of its playing strength. With imperfect scores, or with a different utility scale, this guarantee disappears.

## Which scores can reproduce the source perfectly?

**A board-and-move neural network trained on all boards.** With all 16,167 legal candidates observed, the original 19-input Q chose the source move on 97.39% of the 4,520 boards under squared-error training. Changing only the training loss to binary log loss produced 4,520/4,520. Both used the same initialization, architecture, batches, observations and 300-pass budget. This measures what the network can represent and fit when supplied every position. The withheld-board comparisons above measure prediction at positions where its source labels were unavailable. [Original training comparison](NEURAL_TICTACTOE_CONTROL.md#how-much-difference-did-training-make)

**A single scalar for each resulting board, inferred from choices alone.** The same resulting position can be selected from one parent and rejected from another. Indeed, 2,026 of 5,477 distinct resulting boards have conflicting frequency targets. Yet direct selection requires only that the selected successor outrank its siblings. From the full observed count table we made 11,647 strict comparisons, drawing an arrow from each rejected successor to the selected successor. Following the arrows produced no cycle. Giving each board the length of its longest incoming path yielded just **seven levels, 0 through 6**, and reproduced **4,520/4,520 choices**. This scalar lookup can also be represented by one linear layer with an indicator input per board. It uses observations from every evaluation board. The magnitude of a gap between two such ranks has no measured utility meaning.

**Learning an outcome ordering with explicit best replies.** We allowed a terminal-board model to assign −1, 0 and +1 in any of six orders to an O win, a draw and an X win. For each order we worked backward through legal continuations, with X choosing larger scores and O choosing smaller scores. Training selected the ordering that reproduced the most of the 2,980 observed training choices. Assigning −1 to an O win, 0 to a draw and +1 to an X win reproduced 2,980. The next ordering reproduced 2,661. Direct selection using the resulting board values matched **780/780 withheld moves**. VNM selection using the learned terminal score as the utility of a complete play also matched 780/780 with either continuation rule. All three played exactly like the source on every board. This result uses the game tree, the three terminal categories, the source's tie convention and the assumption of alternating best replies. It identifies an outcome ordering within this model family. Choices under perfect play alone do not identify cardinal utility differences between wins, draws and losses.

| Direct, four further moves | 778/780 (99.74%) | 41.93% | 41.43% | 16.64% |

A useful counterexample comes from the seven-level board ranking above. Direct selection matched all 4,520 moves. Using precisely those ranks as signed, discounted contributions to VNM trajectory utility with source continuations matched 4,094/4,520 (90.58%). A score scale that orders individual moves correctly need not order sums of those scores correctly.

## Reproduction and files

Install the optional libraries with `python -m pip install -e ".[neural-control]"`. Run `python scripts/run_tictactoe_choice_training.py` for the original partition. Repeat the command separately with `--split alternate` for the new partition, `--final-pass` for fixed-duration training, `--data-size` for the nested training subsets, and `--refit-nontest` to train on all non-test boards. Existing files are checked against the regenerated output. The run uses one CPU thread. [Experiment runner](scripts/run_tictactoe_choice_training.py) · [Feature, probability and ranking calculations](src/policy_value_isomorph/choice_training.py)

Repository verification with `pytest -q` passed 74 tests. The demo printed sample board values and chosen moves. Replaying the full-training subset reproduced the fixed-duration fits’ decisions on every board.
