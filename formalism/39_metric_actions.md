# 39 · Choosing from a continuous range

**In plain language.** If an action has a meaningful distance from the player's actual choice, give closer actions higher scores. The original action is the unique best one whenever it is available. If a search only offers a short list, its best possible error is the distance to the nearest offered action. [Common notation](00_notation.md)

A **metric** d assigns nonnegative, symmetric distances, obeys the triangle inequality and gives distance zero exactly for identical points. Let x denote a decision context, p(x) its known deterministic action, and C(x) the offered subset of one metric action space.

**Theorem and proof.** Put `S(x,a) = −d(a,p(x))`. If p(x) belongs to C(x), it scores zero and every distinct action scores strictly less. That proves unique decoding without any assumption of compactness. For a restricted menu B the supremum of S (its least upper bound) is −r where `r = inf{d(a,p(x)): a in B}`. Every maximizer achieves distance r. A nonempty compact B attains the infimum by continuity, as does any nonempty finite B. On any nonempty B one can approach the infimum arbitrarily closely. If only approximate scores are available, with error at most e everywhere on B, choosing within η of their supremum gives a distance at most `r + 2e + η`: the best true score changes by at most e, the selection gives up at most η in fitted score, and the selected score can change by at most another e.

**Measurability.** To average errors over contexts, assume contexts have a specified collection of measurable events, the action space is a separable metric space with its Borel sets (sets generated by the open sets), and p is measurable. Then the pair (a,p(x)) is measurable in the product space and distance is continuous, so S is measurable. Restrict it to a measurable feasible graph of context–action pairs. The original p is already a measurable selector when feasible. For a finite list of measurably generated candidates, first-maximum selection amounts to finitely many measurable score comparisons. Existence of a closest point for each context alone would leave the rule for choosing measurably among ties unspecified.

**Examples.** A steering controller asking for 0.37 radians on [−1,1] has optimal score zero there. On the grid below the nearest angle is 0.25, an error of 0.12 radians. In the plane, a controller requesting (1,2) on a rectangle containing that point has its unique best score there under Euclidean distance. For target 0 and menu (0,1), progressively smaller positive actions approach zero, but every offered action has a closer competitor. If distinct actions can have distance zero (a *pseudometric*), one can recover their zero-distance class and use an additional observation or tie rule to distinguish its members.

```pycon
>>> from fractions import Fraction as F
>>> from math import dist
>>> target = F(37,100)
>>> grid = [F(i,4) for i in range(-4,5)]
>>> best = max(grid, key=lambda a: -abs(a-target))
>>> best, abs(best-target)
(Fraction(1, 4), Fraction(3, 25))
>>> point = (1,2)
>>> [dist(a, point) for a in [point, (4,6)]]
[0.0, 5.0]
>>> assert all(0 < a/2 < a for a in [F(1,2), F(1,8), F(1,128)])
>>> assert abs(abs(-1)-abs(1)) == 0

```

**Self-review.** This construction requires the source action at encoding time. Finite candidate coverage quantifies one loss when using it in practice. How a separately trained model predicts that action at a new context remains an empirical question.
